# Villa Casaggiori — sito web

Restyling responsive in HTML, CSS e JavaScript vanilla. Nessun framework o build step richiesto.

## Struttura
- `index.html` — contenuti e struttura delle sezioni.
- `src/styles.css` — stile, layout responsive e componenti visivi.
- `src/main.js` — menu mobile, galleria lightbox e anno automatico.
